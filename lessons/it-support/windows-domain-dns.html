Windows domain & DNS.

The commands to check a domain, troubleshoot DNS and trace a connection — with simple explanations of what each result means.

15 commands · 1 key concept · Updated 27 Nov 2026

Example values used on this page

Short domain EXAMPLEDNS domain ad.example.comTarget IP 192.0.2.25

Replace these examples with the correct values for your environment before running a command. The domain and IP are reserved for documentation; the IP does not represent a live server. Example domains · Documentation IP ranges

A useful order

  1. Connect to your corporate network or VPN.
  2. Check computer membership and network settings.
  3. Check DNS records, then discover a domain controller.
  4. Choose a refresh action only if the issue calls for it.
  5. Trace the route if you suspect a network path issue.

Which window do I open?

Use Command Prompt for CMD examples. Open PowerShell for Get-CimInstance.

For commands marked admin, choose “Run as administrator.” If nltest is unavailable, check with IT for the appropriate AD administration tools.

The copy buttons copy one command at a time. Nothing on this page runs a Windows command.

16 reference cards
01

Your PC and domain

Find the network settings and separate the user’s domain from the computer’s membership.

Command Prompt

Inspect network settings

Shows the full network configuration.

COMMAND
ipconfig /all

Look for / use whenCheck DNS servers, IPv4 address, gateway and DNS suffixes on the active adapter.

For internal domain lookups, use the DNS configuration provided by your IT team.

Microsoft: ipconfig

Command Prompt

Which domain is my user in?

Displays the DNS domain variable for the current user session.

COMMAND
echo %USERDNSDOMAIN%

Look for / use whenA domain account may show ad.example.com. A local account may leave the variable unset.

This is user/session information. It does not prove computer membership or current connectivity. In PowerShell, use $env:USERDNSDOMAIN.

Microsoft: DNS and logon domain names

Command Prompt

Read the computer’s domain line

Filters system information to the domain or workgroup line.

COMMAND
systeminfo | findstr /B /I /C:"Domain"

Look for / use whenFor example: Domain: ad.example.com. /B matches the beginning of a line; /I ignores letter case.

This filter assumes English Windows output. For other display languages, use the PowerShell check below.

Microsoft: findstr · Computer domain properties

PowerShellPreferred method

Check computer membership

Shows the computer’s domain or workgroup and its AD membership flag.

COMMAND
Get-CimInstance -ClassName Win32_ComputerSystem | Select-Object Domain, PartOfDomain

Look for / use whenPartOfDomain = True means the computer is configured as an AD domain member. If False, Domain can show a workgroup.

This checks membership configuration; it does not test whether a domain controller is reachable.

Microsoft: Computer domain properties · Get-CimInstance

Command PromptLegacy

Recognize the old WMIC command

On older systems that include WMIC, shows the computer’s domain or workgroup.

COMMAND
wmic computersystem get domain

Look for / use whenThe spelling is wmic computersystem. Use the PowerShell command above on current Windows.

Microsoft lists WMIC as removed from Windows 11 24H2 and later from August 2026, with no Feature on Demand. WMI itself is still supported.

Microsoft: WMIC removal

02

Find a domain controller

A domain controller (DC) handles services such as domain sign-in and directory lookups.

Command Prompt · adminStart here

Find a DC using the full domain

Asks Windows to locate a domain controller for the DNS domain.

COMMAND
nltest /dsgetdc:ad.example.com

Look for / use whenRead the DC name, address and completion status. The name might be dc01.ad.example.com.

A returned DC does not prove every domain service or the computer’s trust is healthy.

Microsoft: Nltest · Domain discovery troubleshooting

Command Prompt · admin

Try the short domain name

Locates a DC using the domain’s short name.

COMMAND
nltest /dsgetdc:EXAMPLE

Look for / use whenEXAMPLE represents a NetBIOS domain name. It is a different name format from ad.example.com.

Prefer the full DNS domain for routine troubleshooting. Short-name discovery depends on the environment.

Microsoft: Domain discovery troubleshooting

Command Prompt · admin

Ask for fresh DC discovery

Forces rediscovery instead of using cached DC location information.

COMMAND
nltest /dsgetdc:ad.example.com /force

Look for / use whenUseful after correcting DNS or restoring the corporate network/VPN connection.

The correct switch is /dsgetdc: — include the slash and the letter s. /force does not repair the domain trust.

Microsoft: Nltest

03

Check DNS

DNS translates names into addresses. Active Directory also uses service records to find its servers.

Command Prompt

Look up a DNS name

Queries DNS for address records for the name.

COMMAND
nslookup ad.example.com

Look for / use whenThe Server line identifies the DNS server used; the answer section shows returned records.

This lookup alone does not test AD service discovery. Check the SRV records below too.

Microsoft: nslookup · Active Directory SRV records

Command PromptAD DNS check

Find AD service records

Queries the SRV records that advertise domain controllers.

COMMAND
nslookup -type=SRV _ldap._tcp.dc._msdcs.ad.example.com

Look for / use whenLook for DC target names and their advertised LDAP service port.

A DNS record being present does not by itself prove the target service is reachable.

Microsoft: Active Directory SRV records · nslookup

Command Prompt

Inspect the local DNS cache

Shows the DNS resolver cache on this computer.

COMMAND
ipconfig /displaydns

Look for / use whenReview cached names and records before deciding whether to clear them.

This inspects the client cache, not the full DNS server database.

Microsoft: ipconfig

04

Refresh when needed

Choose the action that matches the issue. These commands do different jobs.

Command Prompt · adminCache change

Clear cached DNS answers

Clears the local DNS resolver cache, including cached failed lookups.

COMMAND
ipconfig /flushdns

Look for / use whenUse when stale cached answers may be involved, then retry the affected lookup.

It does not change your DNS servers or fix incorrect server records.

Microsoft: ipconfig

Command Prompt · adminRegistration request

Request DNS registration

Requests dynamic registration of this computer’s configured DNS names and IP addresses.

COMMAND
ipconfig /registerdns

Look for / use whenUse for a client DNS registration issue. Starting the request does not confirm it succeeded.

Registration depends on network access and DNS update permissions. It is different from clearing the cache.

Microsoft: ipconfig

Command PromptApplies policy

Reapply Group Policy

Reapplies user and computer Group Policy settings, including unchanged settings.

COMMAND
gpupdate /force

Look for / use whenRead both user and computer policy results. Some settings require a sign-out or restart.

Connect to the corporate network or VPN for domain policies. This does not repair DNS or install Windows updates.

Microsoft: gpupdate

05

Trace and understand

Check the route, then understand what “Node Type: Hybrid” actually means.

Command Prompt

Trace the route to an address

Shows responding network hops toward the destination.

COMMAND
tracert 192.0.2.25

Look for / use whenAsterisks mean a hop did not reply in time. They do not automatically prove the route is broken.

Optional: tracert /d 192.0.2.25 skips reverse DNS lookups for intermediate hops. Replace the example address before running.

Microsoft: tracert

Concept · ipconfig /allRemember this

Node Type: Hybrid

This describes a legacy NetBIOS name-resolution method.

1Ask WINSTry a NetBIOS name server.
2Try broadcastIf that lookup does not resolve it.

Easy memory aidHybrid = WINS first, broadcast second.

This order is about NetBIOS name resolution. It does not tell you whether DNS is working or whether the device is Microsoft Entra hybrid joined. You do not need to change the node type just because it says Hybrid.

Microsoft: NetBIOS node types

Syntax corrections to remember

wmic computersystem get domain — spell both words correctly; prefer the PowerShell alternative on current Windows.

nltest /dsgetdc:ad.example.com — the switch is /dsgetdc:, including the slash and s.

ipconfig /registerdns — use a space between the command and its switch for clear, standard formatting.

systeminfo | findstr /B /I /C:"Domain" — /I makes the filter case-insensitive.

echo %USERDNSDOMAIN% — use this syntax in Command Prompt. PowerShell uses $env:USERDNSDOMAIN.
